You already write good software. What this book adds is range: the ability to walk into a team running Spring, ASP.NET, Go or Django and be useful in the first week, and to argue for one of them with reasons rather than habit. To get there, every backend idea is explained once, in plain words and a diagram, and then shown in each stack, side by side.

## How a chapter is built

Every chapter follows the same rhythm, so you always know where you are. It opens with a short list of earlier ideas to load, teaches the concept, shows it in five stacks, and closes with a quiz and a few flashcards.

## The Five Stacks block

This is the heart of the book. Below is the smallest useful backend in each stack: one endpoint that answers `GET /health` with JSON. On the web, pick a tab and every other block in the book switches to the same language. In print, all five appear one under another.

<FiveStacks note="Full code: github · shelfwise">
<Stack id="express" lib="Express">
```ts
import express from 'express';

const app = express();
app.get('/health', (_req, res) => res.json({ status: 'ok' }));
app.listen(3000);
```
</Stack>
<Stack id="cs" lib="ASP.NET Core Minimal API">
```csharp
var app = WebApplication.Create(args);

app.MapGet("/health", () => new { status = "ok" });
app.Run();
```
</Stack>
<Stack id="java" lib="Spring Boot">
```java
@RestController
class HealthController {
    @GetMapping("/health")
    Map<String, String> health() { return Map.of("status", "ok"); }
}
```
</Stack>
<Stack id="go" lib="net/http">
```go
http.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(map[string]string{"status": "ok"})
})
http.ListenAndServe(":3000", nil)
```
</Stack>
<Stack id="fastapi" lib="FastAPI">
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```
</Stack>
</FiveStacks>

Notice what is already different. Spring needs a class and annotations; ASP.NET and FastAPI register a function; Go writes headers and encodes JSON by hand. Each of those differences is a design philosophy, and we will name them as we go.
